# Changelog — Dzion Hub Squad

## [0.1.0] - 2026-08-03

### Added
- Squad scaffolding (`config.yaml`, `README.md`) following the
  `squads/claude-code-mastery` convention.
- Tier 0 agent `aiox-chief-architect` (codename Axis) — governance, context
  engineering, anti-invention, anti-duplication, complexity ROI gate.
- Tier 1 agent `brand-chief` (codename Norte) — brand strategy: positioning,
  differentiation, audience, transformation, archetypes, voice, messaging.
- Task `tasks/create-context.md` — 11-phase context engineering workflow.
- Task `tasks/build-brand-system.md` — 11-phase brand system build/review workflow.
- Checklist `checklists/context-quality-gate.md`.
- Checklist `checklists/brand-quality-gate.md`.
- `context/` structure with 7 categories (founder, audience, brands, offers,
  methods, evidence, research), all empty by design with explicit
  `_pending.md` markers — no factual content invented.
- `decisions/decision-log.md` with the first structural decision recorded.

### Explicitly not included (Phase 1 scope)
- Copy Squad, Design Squad, Growth Squad, Sales Squad, Finance Squad, Risk Squad.
- `playbooks/` per channel/format.
- Automated (hook-based) enforcement of quality gates — currently agent-applied only.
