Antes de criar qualquer arquivo novo de contexto, **leia este índice primeiro**
para evitar duplicação — ver `tasks/create-context.md`, Precondition 1.

Nenhum conteúdo factual sobre a Dzion Hub foi inventado para preencher esta
Fase 1. Todas as pastas abaixo existem como estrutura pronta para receber
conteúdo real, mas estão vazias por padrão — ver marcador `_pending.md` em
cada uma.

## Como usar este índice

1. Antes de escrever qualquer contexto novo, procure aqui se já existe algo equivalente.
2. Ao adicionar um arquivo, adicione uma linha na tabela da categoria correspondente
   (crie a subseção se ainda não existir) com: nome do arquivo, um resumo de uma
   linha, e a versão atual.
3. Nunca duplique o mesmo fato em duas categorias — se um fato pertence a duas,
   escolha a fonte canônica e referencie a partir da outra.
