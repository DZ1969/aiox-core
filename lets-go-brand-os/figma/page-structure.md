# Figma Page Structure

## Páginas recomendadas (nesta ordem)

1. **00 — Cover & Guide** — como navegar o arquivo, link para `lets-go-brand-os/README.md`
2. **01 — Foundations** — paleta, tipografia, grid, espaçamento (espelha `tokens/tokens.json`)
3. **02 — Components** — botões/CTA, cartões de rota, cartões de preço/fonte, disclosure, badges de verdict
4. **03 — Templates / Editorial Escape** — os templates aplicáveis a essa família visual
5. **04 — Templates / Field Notes** — os templates aplicáveis a essa família visual
6. **05 — Templates / Brand Story-UGC** — os templates aplicáveis a essa família visual
7. **06 — Bilingual Layouts** — pares PT/EN lado a lado do mesmo componente, testando overflow (`brand/06-bilingual-rules.md`)
8. **07 — Examples: Approved / Rejected** — biblioteca viva de exemplos certos e errados
9. **08 — Campaign Workspace** — página de trabalho ativo, não uma página "modelo" — onde campanhas reais são montadas a partir dos templates
10. **09 — Archive** — versões antigas de templates, mantidas para histórico, não para uso

## Regras de organização

- Nenhum template solto fora de sua página de família visual
- Frames de exemplo aprovado/rejeitado sempre emparelhados lado a lado com anotação do motivo
- Página de Campaign Workspace nunca deve ser confundida com as páginas de template — duplicar o componente antes de editar, nunca editar o mestre diretamente
