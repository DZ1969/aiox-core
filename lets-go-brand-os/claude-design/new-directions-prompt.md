# Prompt — Novas Direções de Arte

> Usar quando explorar variações visuais dentro do sistema, sem quebrar a marca.

```text
Gere variações de direção de arte para [descrever peça/campanha] dentro do Brand OS da Let's Go With Francis.

Restrições obrigatórias:
- Paleta: apenas travel ink (#101417), warm white (#FAF7F1), sand (#D8C7AE), heritage gold (#B99155),
  ocean teal (#1C6B70), action green (#0B6B43), coral alert (#C35A4A). Ver tokens/tokens.json.
- Tipografia: Fraunces (títulos editoriais) + DM Sans (corpo/CTA), IBM Plex Mono só para dado técnico.
- Direção fotográfica: quiet luxury, editorial de revista — não catálogo turístico (brand/05-photo-and-video-direction.md).
- Família visual: escolher entre Editorial Escape, Field Notes, ou Brand Story/UGC (social/carousel-system.md)
  — não misturar as três na mesma peça sem justificativa.
- Não inventar logo, fotografia ou identidade não fornecida. Usar placeholder identificado se faltar ativo real.
- Não modificar rosto/corpo de Francis se ela estiver presente.

Gere 3 variações de composição para a mesma família visual escolhida, cada uma com:
- Descrição da composição (o que ocupa cada terço do canvas)
- Papel de cada cor da paleta na peça
- Onde entra o elemento de fonte/data/CTA/disclosure (se aplicável)

Ao final, indique qual variação melhor atende ao objetivo declarado e por quê.
```
