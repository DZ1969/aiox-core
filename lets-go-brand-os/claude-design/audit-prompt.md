# Prompt — Auditoria de Peça Existente

> Copiar e colar em sessão de Claude Design (ou usar como checklist manual) para auditar uma peça já publicada ou em rascunho contra o Brand OS.

```text
Audite a peça anexada contra o Brand OS da Let's Go With Francis.

Verifique, item a item:
1. Paleta: usa apenas as 7 cores de brand/04-visual-system.md? Teal só para descoberta/localização, verde só para CTA, coral só para alerta real?
2. Tipografia: Fraunces em títulos editoriais, DM Sans em corpo/CTA, IBM Plex Mono só quando há dado tabular/técnico?
3. Contraste: todo texto atinge no mínimo AA sobre o fundo usado (brand/07-accessibility.md)?
4. Safe zones: respeita as margens do formato (social/safe-zones.md)?
5. Direção fotográfica: evita HDR excessivo, céu falso, pose repetida, avião genérico, mapa decorativo, colagem poluída (brand/05-photo-and-video-direction.md)?
6. Francis (se presente): está reconhecível, sem alteração de rosto/corpo?
7. Voz: usa vocabulário aprovado, evita lista de termos proibidos (content/approved-language.md, content/prohibited-language.md)?
8. Fonte/data: todo preço, regra ou dado factual tem fonte e data, ou está marcado [VERIFICAR FONTE E DATA]?
9. Disclosure: se há relação comercial, o disclosure está visível no primeiro ponto de contato?
10. Bilíngue (se aplicável): a versão no outro idioma existe como conteúdo nativo, não tradução literal?

Para cada item, responda: PASSA / FALHA / NÃO SE APLICA — com justificativa de uma frase.
Ao final, liste as correções necessárias em ordem de prioridade.
```
