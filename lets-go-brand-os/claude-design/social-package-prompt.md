# Prompt — Pacote Social Completo

> Usar para gerar um pacote de conteúdo social (carrossel + story + reel cover) a partir de um brief já preenchido.

```text
Monte um pacote social completo para o brief anexado (content/destination-brief-template.md ou
content/ugc-campaign-template.md preenchido).

Entregue:
1. Carrossel de 9 slides seguindo a estrutura narrativa de social/carousel-system.md
   (gancho, cena, tensão, erro comum, virada, ação prática, prevenção, recapitulação, CTA)
   — ou estrutura equivalente adequada ao tipo de conteúdo (destino/roteiro/review).
2. Capa de carrossel que funcione como thumbnail isolado.
3. 2-3 frames de Story derivados do carrossel (social/story-system.md).
4. 1 reel cover (social/reel-cover-system.md), respeitando safe zone de grid.

Regras não negociáveis:
- Toda informação de preço/regra/data cita fonte e data, ou usa [VERIFICAR FONTE E DATA].
- Toda peça respeita safe zones do formato (social/safe-zones.md).
- Gerar em PT-BR e EN-US como conteúdo adaptado, não tradução literal (brand/06-bilingual-rules.md),
  em arquivos separados.
- Se não houver fotografia real fornecida, usar placeholder de cor sólida com legenda [FOTO A DEFINIR]
  — nunca imagem de banco genérica.
- Marcar todo o pacote como DEMONSTRAÇÃO se o brief não tiver sido confirmado como campanha real.

Ao final, liste os campos de dados estruturados necessários para popular o pacote em studio/src/data/.
```
