# UGC Shot List — Template

> Usar para orientar produção de fotografia/vídeo UGC (própria ou de parceiro), garantindo que o mix de imagem siga `brand/05-photo-and-video-direction.md`.

```yaml
shot_list:
  campanha: ""
  local: ""
  data: ""

  shots:
    - tipo: "establishing"        # establishing | detalhe | comida | arquitetura | pessoas | momento-humano
      descricao: ""
      obrigatorio: true
    - tipo: "detalhe"
      descricao: ""
      obrigatorio: true
    - tipo: "momento-humano"
      descricao: ""
      obrigatorio: true

  direcao_de_francis:
    natural: true                 # sem retoque estrutural de rosto/corpo
    gestos: "críveis, não posados em excesso"

  o_que_evitar:
    - "HDR excessivo"
    - "céu substituído"
    - "pose repetida"
    - "avião genérico como recurso"
    - "mapa decorativo sem função"

  licenciamento:
    fotografo: ""
    licenca_confirmada: false
```

## Checklist mínimo de cobertura por campanha

- [ ] Pelo menos 1 establishing shot
- [ ] Pelo menos 1 detalhe
- [ ] Pelo menos 1 momento humano genuíno (não posado)
- [ ] Comida/arquitetura incluídos quando relevantes ao contexto
- [ ] Nenhum shot depende de céu falso, HDR ou pose repetida
