# Brand/Partner Intake Brief

> Formulário para uma marca/parceiro propor colaboração com Let's Go With Francis. Preencher antes de qualquer negociação avançar. Alimenta `content/ugc-campaign-template.md`.

```yaml
marca:
  nome: ""
  contato: ""
  categoria: ""                  # hospedagem | companhia-aerea | produto-de-viagem | outro

proposta:
  tipo_de_relacao: ""            # produto-gratuito | pago | affiliate | outro
  o_que_a_marca_oferece: ""
  o_que_a_marca_espera: ""

compatibilidade_de_marca:
  alinha_com_pilares: null       # sim/não — ver brand/01-foundation.md e content/content-pillars.md
  risco_de_credibilidade: ""     # avaliação honesta — a parceria arrisca a confiança da audiência?
  precisa_de_disclosure: true    # quase sempre true quando há produto/pagamento

limites:
  aprova_alteracao_de_avaliacao_real: false   # deve ser sempre false — ver content/review-integrity-rules.md
  aprova_uso_de_logo_como_parceria: null      # só true com confirmação por escrito

decisao:
  aprovado: null
  motivo: ""
  responsavel: ""
  data: ""
```

## Critérios de recusa automática

- Marca pede para alterar avaliação real ou omitir ressalva genuína
- Marca pede para omitir disclosure
- Marca pede uso de logo/nome sugerindo parceria maior do que a real
- Proposta não se alinha a nenhum dos três pilares de conteúdo

## Fluxo

`Intake` → avaliação de compatibilidade → se aprovado, preencher `content/ugc-campaign-template.md` → produção seguindo `ugc/shot-list-template.md` → disclosure conforme `ugc/disclosure-rules.md` → entrega conforme `ugc/deliverables-matrix.md`
